## 1. LITENED NKD / NKK — прямоугольные секции

### 1.1 Правило перевода модельного кода в габариты

Модельный код `LITENED X-Y` — это **условный типоразмер**, который в миллиметрах соответствует:

| Модельный код | Реальное сечение воздуховода (A0 × B0), мм | Длина NKD (L0), мм | Длина NKK (L0), мм |
|---------------|--------------------------------------------|--------------------|--------------------|
| LITENED 40-20 | 400 × 200                                  | 1100               | 510                |
| LITENED 50-25 | 500 × 250                                  | 1100               | 510                |
| LITENED 50-30 | 500 × 300                                  | 1100               | 510                |
| LITENED 60-30 | 600 × 300                                  | 1100               | 510                |
| LITENED 60-35 | 600 × 350                                  | 1100               | 510                |
| LITENED 70-40 | 700 × 400                                  | 1100               | 510                |
| LITENED 80-50 | 800 × 500                                  | 1100               | 510                |
| LITENED 90-50 | 900 × 500                                  | 1100               | 510                |
| LITENED 100-50| 1000 × 500                                 | 1100               | 510                |

### 1.2 Габариты корпуса (для справки)

| Модель        | A, мм | Б, мм | В, мм | Г, мм | Длина D, мм |
|---------------|-------|-------|-------|-------|-------------|
| LITENED 40-20 | 610   | 420   | 535   | 345   | 1100 / 510  |
| LITENED 50-25 | 710   | 470   | 635   | 395   | 1100 / 510  |
| LITENED 50-30 | 710   | 520   | 635   | 445   | 1100 / 510  |
| LITENED 60-30 | 810   | 520   | 735   | 445   | 1100 / 510  |
| LITENED 60-35 | 810   | 570   | 735   | 445   | 1100 / 510  |
| LITENED 70-40 | 910   | 620   | 835   | 545   | 1100 / 510  |
| LITENED 80-50 | 1010  | 720   | 935   | 645   | 1100 / 510  |
| LITENED 90-50 | 1125  | 740   | 1050  | 665   | 1100 / 510  |
| LITENED 100-50| 1225  | 740   | 1150  | 665   | 1100 / 510  |

> Важно: для 1С нужно **сечение воздуховода** (`A0 × B0`), а не габарит корпуса.

### 1.3 Предлагаемая логика парсинга

```text
Если встречается "LITENED <X>-<Y> NKD" или "LITENED <X>-<Y> NKK":
    1. Определить A0 = X * 100, B0 = Y * 100.
    2. Если NKD → L0 = 1100.
    3. Если NKK → L0 = 510.
    4. Артикул по умолчанию = 15-2-1 (прямоугольный трубчатый ГТП).
    5. Если в названии есть "пластинчатый" → 15-2-2, "с обтекателем" → 15-2-3 и т.д.
```

Примеры:
- `Шумоглушитель LITENED 100-50 NKD` → `A0=1000, B0=500, L0=1100, article=15-2-1`.
- `Шумоглушитель LITENED 60-30 NKK` → `A0=600, B0=300, L0=510, article=15-2-1`.

> Сейчас в `process_specification_table.py` `correct_ocr_size` домножает стороны 10–99 мм на 10, но `100` не попадает в диапазон, поэтому `100-50` превращается в неверные `100×500` или остаётся `100×50`. Нужна явная таблица LITENED.

## 2. NED KNK — круглые канальные шумоглушители

### 2.1 Схема обозначения

```text
KNK <D> / <L>
- D — присоединительный диаметр, мм
- L — длина шумопоглощающего участка, ×100 мм
```

### 2.2 Линейка размеров

| Обозначение | D0, мм | L0, мм | Полная длина А, мм | Масса, кг |
|-------------|--------|--------|--------------------|-----------|
| KNK 100/6   | 100    | 600    | 615                | 4,0       |
| KNK 100/9   | 100    | 900    | 915                | 5,4       |
| KNK 125/6   | 125    | 600    | 615                | 4,8       |
| KNK 125/9   | 125    | 900    | 915                | 6,6       |
| KNK 160/6   | 160    | 600    | 615                | 5,8       |
| KNK 160/9   | 160    | 900    | 915                | 7,4       |
| KNK 200/6   | 200    | 600    | 615                | 6,4       |
| KNK 200/9   | 200    | 900    | 915                | 9,2       |
| KNK 250/6   | 250    | 600    | 615                | 7,8       |
| KNK 250/9   | 250    | 900    | 915                | 10,6      |
| KNK 315/6   | 315    | 600    | 615                | 10,4      |
| KNK 315/9   | 315    | 900    | 915                | 14,0      |

> Диаметры: 100, 125, 160, 200, 250, 315. Длины: 600 и 900 мм.

### 2.2 Предлагаемая логика парсинга

```text
Если встречается "KNK <D>/<L>":
    1. D0 = <D> (мм).
    2. L0 = <L> * 100 (мм).
    3. Артикул = 15-1-1 (ГТК), если нет слова "спиральный"; иначе 15-1-2.
```

Примеры:
- `Шумоглушитель KNK 250/6` → `D0=250, L0=600, article=15-1-1`.
- `Шумоглушитель круглый Ф160, L=900 мм KNK-160-900` → `D0=160, L0=900, article=15-1-1`.

> Сейчас `extract_dimensions` вытаскивает только `D0` из `KNK`, а `L0` берётся дефолтный `1000`. Нужно добавить правило `KNK D/L`.

## 3. Корректировка параметров 15-2-4 и 15-2-5 для 1С

### 3.1 Что видит 1С

В `docs/модуль ввод нового заказа.txt`:

- `15-2-4` Пластина шумоглушителя: `Обозначение = B_ + "x" + L_ + "x" + a2_`
- `15-2-5` Обтекатель шумоглушителя: `Обозначение = B_ + "x" + a2_`

В процедуре расчёта:
- `15-2-4`: `B = B/1000; L = L/1000; a2 = a2/1000;`
- `15-2-5`: `B = B/1000; a2 = a2/1000;`

### 3.2 Проблема

В `product_article_mapping.json` для `15-2-4` и `15-2-5` сейчас заданы параметры `A0, B0, A1, B1, L0` — это параметры **готового прямоугольного шумоглушителя**, а не пластины/обтекателя. Параметр `a2` (ширина пластины/обтекателя) отсутствует.

### 3.3 Предлагаемая логика приведения к соответствию

1. **Использовать 15-2-4 / 15-2-5 только при явном указании в исходнике:**
   - `"пластина шумоглушителя"` → `15-2-4`
   - `"обтекатель шумоглушителя"` → `15-2-5`
   - В обычных ведомостях встречаются готовые секции NKD/NKK, их нужно оставлять на `15-2-1/15-2-2/15-2-3`.

2. **Изменить `product_article_mapping.json`:**

   ```json
   {
     "article": "15-2-4",
     "xml_parameters": ["B0", "L0", "A2"],
     "designation_expression": "\"\"+B_+\"x\"+L_+\"x\"+a2_",
     "default_params": {
       "A2": 200
     }
   }
   ```

   ```json
   {
     "article": "15-2-5",
     "xml_parameters": ["B0", "A2"],
     "designation_expression": "\"\"+B_+\"x\"+a2_",
     "default_params": {
       "A2": 200
     }
   }
   ```

   > Значение `A2` (ширина пластины/обтекателя) по умолчанию взято условно **200 мм**. Его лучше уточнить у технолога / в спецификации 1С, т.к. от него зависит расчёт массы и цены.

3. **Добавить форматирование `A2` в `generate_order_xml.py`:**

   В `format_parameter_value` список 4-значных параметров дополнить:

   ```python
   name_upper in ("D0", "D1", "D2", "D3",
                  "A0", "A1", "A2", "A3",
                  "B0", "B1", "B2", "B3",
                  "L0", "L1", "L2", "L3",
                  "P0", "P1", "P2", "P3")
   ```

4. **Парсинг из исходного текста:**

   - Для `15-2-4` искать три числа: `B0 × L0 × A2`.
   - Для `15-2-5` искать два числа: `B0 × A2`.
   - Если чисел меньше — подставлять `default_params`.

   Примеры:
   - `Пластина шумоглушителя 500x1100x200` → `B0=500, L0=1100, A2=200`.
   - `Обтекатель шумоглушителя 500x200` → `B0=500, A2=200`.
