# Исследование расчёта стоимости фасонных изделий в 1С через MCP (порт 6005)

> Дата исследования: 2026-10-20  
> Источники: дамп `docs/модуль ввод нового заказа.txt`, прямые пробы через MCP `http://127.0.0.1:6005`, регистр `асЦеныПродукции`, справочник `асПродукция`, регистр `асНастройкиПродукции`.  
> Цель: понять и задокументировать, как в 1С «ВОК-Регион» рассчитывается стоимость отводов, тройников, переходов и воздуховодов, чтобы повторить логику вне 1С или корректно грузить заказы.

---

## 1. Краткая сводка (TL;DR)

1. Расчёт ведёт обработка `асВводНовогоЗаказа`, метод `РедактироватьВсеНаКлиенте_ДляИзмененныхВМодуле()` (строка ~23407 дампа). Он делает всё за один проход: геометрию, площадь, тип цены, цену за единицу.
2. Для каждой строки сначала вызывается `РасчетФормул()` — по артикулу продукта выбирается ветка геометрии, считаются `Sclean`, `Slock`, `S`, `M`, `V`.
3. Затем `УстановкаПрайсаНаСервере()` расставляет флаги в ТЧ `Прайс` обработки (`ФасонныеИзделияКС/ПС`, `НестандартныеИзделияКС/ПС`, `ПрямойУчастокПС` и т.д.) в зависимости от сечения, длины, площади и специальных параметров продукта.
4. `РасчетЦен()` берёт цену из регистра `асЦеныПродукции.СрезПоследних` по материалу и установленному флагу, после чего `ЦенаЕд = Цена × S` (для фасонки/воздуховодов) плюс цены спецификации/соединений, если есть.
5. Сумма = `ЦенаЕд × n`.

## 2. Инфраструктура и методика пробы

### 2.1 MCP 6005

Проверка доступности и конфигурации:

```bash
curl -s -X POST http://127.0.0.1:6005/api/execute_code \
  -H 'Content-Type: application/json' \
  -d '{"code":"Результат = Метаданные.Имя + \" \" + Метаданные.Версия;"}'
```

Результат:

```json
{"success": true, "data": "КомплекснаяАвтоматизация 2.5.22.170"}
```

Использовались эндпоинты:

- `POST /api/execute_code` — выполнение произвольного кода 1С.
- `POST /api/execute_query` — запросы к базе.

### 2.2 Ключевые объекты

| Объект | Роль |
|---|---|
| `Обработка.асВводНовогоЗаказа` | Точка входа в расчёт |
| `Справочник.асПродукция` | Номенклатура-продукты (артикулы 1-2-1, 2-1-1, 4-1-2 и т.д.) |
| `Справочник.асМатериалы` | Материалы листов/рулонов (`Рулон оц.(08ПС)0.80`, `Лист.нерж. (AISI 430) 0.80` и др.) |
| `РегистрСведений.асЦеныПродукции` | Цены по типам и материалам |
| `РегистрСведений.асНастройкиПродукции` | Производные размеры (`a1`, `b1`, `d1`, `R`, `p`, `L0` и др.) |
| `Справочник.асСоединениеВоздуховодов` | Шина/уголок и др. |

### 2.3 Тестовый расчёт одной строки

Код создаёт обработку, добавляет строку в ТЧ `Заказы`, заполняет продукт, материал, соединение, размеры, ставит `ТребуетсяПересчет = Истина` и вызывает `РедактироватьВсеНаКлиенте_ДляИзмененныхВМодуле()`. Пример для отвода 2-1-1 D200 R200 угол 90:

```bsl
О = Обработки.асВводНовогоЗаказа.Создать();
О.ТекущаяПрограмма1С = "КА";
О.УчитыватьЗамкиВРасчетеПлощадиДляСчета = Истина;
О.ДатаУстановкиЦен = ТекущаяДата();

Стр = О.Заказы.Добавить();
Стр.Продукт              = Справочники.асПродукция.НайтиПоРеквизиту("Артикул", "2-1-1");
Стр.АртикулПродукции     = "2-1-1";
Стр.АртикулГруппы        = "2";
Стр.Номенклатура         = Стр.Продукт.Продукт;
Стр.СечениеСтр           = Перечисления.асВидыСечений.Круглое;
Стр.ГруппаПродукцииСтр   = Стр.Продукт.ГруппаПродукции;
Стр.Материал             = Справочники.асМатериалы.НайтиПоНаименованию("Рулон оц.(08ПС)0.80", Истина);
Стр.МатериалНаСоединение0 = Справочники.асПродукция.НайтиПоНаименованию("Шина 20 / УГФ 65", Истина);
Стр.СоединениеВоздуховода_c0 = Справочники.асСоединениеВоздуховодов.НайтиПоНаименованию("Шина / уголок", Истина);
Стр.СоединениеВоздуховода_c1 = Стр.СоединениеВоздуховода_c0;
Стр.D0 = 200;
Стр.R  = 200;
Стр.u  = 90;
Стр.n  = 1;
Стр.t  = 0.8;
Стр.ТребуетсяПересчет = Истина;

О.РедактироватьВсеНаКлиенте_ДляИзмененныхВМодуле();
```

| Показатель | Значение |
|---|---|
| `S` | 0.254 |
| `Sclean` | 0.197 |
| `Slock` | 0.057 |
| `Цена` | 2091 |
| `ЦенаЕд` | 531 |
| `ТипЦеныПоПрайсу` | `ФасонныеИзделияКС` |
| `КоличествоСоединений` | 2 |

- `Круглое` — КС-цены (`ФасонныеИзделияКС`, `НестандартныеИзделияКС`, `ПрямойУчастокКС` и т.д.).
- `Прямоугольное` — ПС-цены (`ФасонныеИзделияПС`, `НестандартныеИзделияПС`, `ПрямойУчастокПС` и т.д.).
- `Переходное` — обычно ПС-цены (переходы/тройники с разнородными врезками).

## 4. Алгоритм расчёта

### 4.1 Общий пайплайн

```
Вход: строка ТЧ Заказы обработки асВводНовогоЗаказа
   ↓
РасчетФормул()              ← по АртикулГруппы + АртикулПродукции
   ↓
УстановкаПрайсаНаСервере()  ← флаги ТЧ Прайс по сечению/длине/площади
   ↓
РасчетЦен(Материал, Материал2)
   ↓
РасчетЦеныЗаЕдиницу()
   ↓
Выход: S, Sclean, Slock, M, V, Цена, ЦенаЕд, ТипЦеныПоПрайсу, Сумма
```

### 4.2 Расчёт геометрии (`РасчетФормул`)

По артикулу группы:

- `1` — `Воздуховод(...)`
- `2` — `Отвод(...)`
- `3` — `ПереходКруглое(...) / ПереходПрямоугольное(...) / ПереходПереходного(...)`
- `4` — `ТройникКруглое(...) / ТройникПрямоугольное(...)`
- `5` — `Крестовина(...)`
- `15` — `Шумоглушитель(...)`

Каждая групповая процедура — цепочка `Если АртикулПродукции = "..."`.

Универсальный финальный блок в каждой ветке:

```bsl
S     = ?(УчитыватьЗамкиВРасчетеПлощадиДляСчета, Sclean + Slock, Sclean);
M     = S * Pz;          // Pz из справочника асМатериалы, кг/м²
Отход = M * ОтходПроцент / 100;
```

> Важно: в ветке отвода 2-1-1 масса считается иначе — `M = (Sclean + Slock + ОтходДляS) * Pz` (всегда с замками), но внешний расчёт `S` всё равно зависит от флага `УчитыватьЗамкиВРасчетеПлощадиДляСчета`.

### 4.3 Ключевые формулы

#### Воздуховод круглый прямошовный `1-1-1`

```bsl
Slock  = L * Lock1;
Sclean = pi() * D * L;
V      = pi() * pow(D, 2) * L / 4;
```

#### Воздуховод спиральный `1-1-2`

```bsl
Hsh    = 137/1000 - Lock1;
Nv     = L / Hsh;
Lv     = sqrt(pow(pi()*D, 2) + pow(Hsh, 2));
Lsh    = Nv * Lv;
Slock  = Lsh * Lock1;
Sclean = pi() * D * L;
```

#### Воздуховод прямоугольный `1-2-1`

```bsl
Slock  = 2 * L * Lock1;
Sclean = 2 * (A + B) * L;
V      = A * B * L;
```

#### Отвод круглый радиусный `2-1-1`

```bsl
Dlina_Osi = pi() * R * u / 180 + p + p1;
Perimetr  = pi() * D;
Sclean    = round(Szv * Nz + Perimetr * p + Perimetr * p1, 4);
Slock     = round(Dlina_Osi * Lock1 + Perimetr * Lock2, 4);
M         = (Sclean + Slock + ОтходДляS) * Pz;
V         = round((pi() * pow(D, 2) / 4) * Dlina_Osi, 4);
```

Константы замков (CAMduct):

```bsl
Lock1 = 0.006;   // припуск на замок по длине дуги
Lock2 = 0.0875;  // поперечный припуск
```

#### Отвод круглый конический `2-1-2`

```bsl
L_obr  = sqrt(pow(R * u * pi() / 180, 2) + pow((D - d1) / 2, 2));
Sside  = (pi() / 2) * (D + d1) * L_obr;
Spr    = pi() * D * p + pi() * d1 * p1;
Sclean = round(Sside + Spr, 3);
Slock  = 2 * ДлинаЦентральнойДуги * Lock1 + (pi() * (D + d1) / 2) * 3 * Lock2 + pi() * (D + d1) * Lock3;
```

#### Отвод прямоугольный радиусный `2-2-1`

```bsl
Sbok   = pi() * (pow(Rzat, 2) - pow(Rsh, 2)) * u / 360 + A * p + A * p1;
Ssh    = (Lsh + p + p1) * B;
Szat   = (Lzat + p + p1) * B;
Sclean = round(2 * Sbok + Ssh + Szat, 4);
Slock  = 2 * (Lsh + p + p1) * Lock1 + 2 * (Lzat + p + p1) * Lock1;
```

#### Переход круглый односторонний `3-1-2`

```bsl
lob_0   = sqrt(pow(L, 2) + pow(D - d1, 2));
lob_90  = sqrt(pow(L, 2) + pow((D - d1) / 2, 2));
lob_180 = L;
lob_270 = lob_90;
lob_sr  = sqrt((pow(lob_0, 2) + pow(lob_90, 2) + pow(lob_180, 2) + pow(lob_270, 2)) / 4);
Sbok    = pi() * (D/2 + d1/2) * lob_sr;
Spr     = pi() * (D * p + d1 * p1);
Sclean  = round(Sbok + Spr, 3);
Slock   = (lob_0 + p + p1) * Lock1 + pi() * (D + d1) * Lock2;
V       = 1/3 * pi() * L * (pow(D/2, 2) + D/2 * d1/2 + pow(d1/2, 2)) + pi() * pow(D, 2)/4 * p + pi() * pow(d1, 2) * p1;
```

#### Тройник круглый с косой врезкой `4-1-2`

```bsl
Sstv  = pi() * D * L;
Os1   = d2 / sin(u * pi() / 180);
beta  = 2 * asin(d2 / D) * 180 / pi();
Svr   = (Hleft + Hright) * (pi() * d2 / 2);
Sotv  = pi() * Os1 / 2 * Os2 / 2;
Spr   = 2 * pi() * D * p + pi() * d2 * p2;
Sclean = round(Sstv - Sotv + Svr + Spr, 3);
```

### 4.4 Параметры из регистра `асНастройкиПродукции`

Регистр хранит производные размеры. Правило: применять **только к нулевым полям** строки, иначе перезапишем размеры из спецификации/заказа.

Примеры (получены через MCP):

| Артикул | Параметр | Вариант | Значение | Зависимость |
|---|---|---|---|---|
| `2-1-1` | `R` | Вариант2 | `D0 + 0` | радиус по умолчанию равен диаметру |
| `2-1-2` | `R` | Вариант2 | `D0 × 1` | — |
| `2-2-1` | `R` | Вариант1 | 100 | константа |
| `3-1-2` | `p`, `p1` | Вариант1 | 50 | константа |
| `3-2-1` | `p`, `p1` | Вариант1 | 35 | константа |
| `4-1-2` | `L0` | Вариант2 | `minimum + 200` | — |
| `4-1-2` | `l2` | Вариант2 | `minimum + 20` | — |
| `4-2-3` | `L0` | Вариант2 | `a2 + 100` | — |

## 5. Установка типа цены (`УстановкаПрайсаНаСервере`)

### 5.1 Общий принцип

Обработка содержит служебную ТЧ `Прайс`. В ней для строки устанавливаются булевы флаги. `РасчетЦен` читает первый установленный флаг и берёт соответствующую колонку регистра.

Ключевые типы цен:

| Флаг | Колонка регистра | Когда используется |
|---|---|---|
| `СпиральноНавивной` | `СпиральноНавивной` | Воздуховод круглый спиральный 1-1-2 |
| `ПрямойУчастокКС` | `ПрямойУчастокКС` | Круглый воздуховод стандартной длины |
| `ПрямойУчастокПС` | `ПрямойУчастокПС` | Прямоугольный воздуховод стандартной длины |
| `ФасонныеИзделияКС` | `ФасонныеИзделияКС` | Круглые отводы, переходы, тройники и др. |
| `ФасонныеИзделияПС` | `ФасонныеИзделияПС` | Прямоугольные отводы, переходы, тройники и др. |
| `НестандартныеИзделияКС` | `НестандартныеИзделияКС` | Маленькая площадь или флаг продукта «цена по нестандарту» |
| `НестандартныеИзделияПС` | `НестандартныеИзделияПС` | То же для прямоугольного сечения |
| `ПоЦенеИзделия` | — | Цена по спецификации/группам/фланцам |

### 5.2 Круглое сечение (КС)

```bsl
Если АртикулГруппы = "1" Тогда  // воздуховод
    Если L0 = ДлинаПрямогоСтандартногоУчастка Тогда
        ПрямойУчастокКС = Истина;
    Иначе
        ПрямойУчастокКС1 = Истина;  // нестандартная длина
    КонецЕсли;
Иначе  // фасонка
    ФасонныеИзделияКС = Истина;
КонецЕсли;

Если Продукт.ЦенаПоНестандартномуИзделию Тогда
    НестандартныеИзделияКС = Истина;
КонецЕсли;

Если S < ПлощадьМинимальнаяФасонногоИзделияДляНестандартнойЦены Тогда
    // маленькая фасонка → нестандартная цена
    ФасонныеИзделияКС = Ложь;
    НестандартныеИзделияКС = Истина;
КонецЕсли;
```

### 5.3 Прямоугольное/переходное сечение (ПС)

```bsl
Если АртикулГруппы = "1" Тогда  // воздуховод
    Если L0 = Длина1 Тогда
        ПрямойУчастокПС = Истина;
    ИначеЕсли Длина2 <= L0 <= Длина3 Тогда
        ПрямойУчастокПС1 = Истина;
    Иначе
        ПрямойУчастокПС2 = Истина;
    КонецЕсли;
Иначе
    ФасонныеИзделияПС = Истина;
КонецЕсли;

Если A0 <= ПрямоугольныйСоСторонойМеньше ИЛИ B0 <= ПрямоугольныйСоСторонойМеньше Тогда
    ФасонныеИзделияПС = Истина;  // малое сечение → фасонная цена
КонецЕсли;

Если Продукт.ЦенаПоНестандартномуИзделию Тогда
    НестандартныеИзделияПС = Истина;
КонецЕсли;

Если ПрямойУчастокПС И S < МинимальнаяПлощадьПрямогоУчастка Тогда
    // маленький прямой участок → как фасонка
    ПрямойУчастокПС = Ложь;
    ФасонныеИзделияПС = Истина;
КонецЕсли;

Если ФасонныеИзделияПС И S < ПлощадьФасонногоИзделияДляНестандартнойЦеныДляПрямоугольного Тогда
    // маленькая фасонка → нестандарт
    ФасонныеИзделияПС = Ложь;
    НестандартныеИзделияПС = Истина;
КонецЕсли;
```

### 5.4 Пороговые значения (регистр `асЦеныПродукции`, материал `Рулон оц.(08ПС)0.80`)

| Параметр | Значение |
|---|---|
| `ДлинаПрямогоСтандартногоУчастка` | 1250 мм |
| `ДлинаПрямогоУчасткаДляЦеныФасонныхИзделий` | 1250 мм |
| `ДлинаПрямогоУчасткаДляЦеныФасонныхИзделий1` | 3000 мм |
| `МинимальнаяПлощадьПрямогоУчастка` | 0.49 м² |
| `ПлощадьФасонногоИзделияДляНестандартнойЦеныДляПрямоугольного` | 0.10 м² |
| `ПлощадьМинимальнаяФасонногоИзделияДляНестандартнойЦены` | 0.19 м² |
| `ПлощадьМинимальнаяФасонногоИзделияДляНестандартнойЦены1` | 0.19 м² |

> Эти значения хранятся в регистре цен и могут отличаться для других материалов.

## 6. Расчёт цены (`РасчетЦен`)

### 6.1 Источник цены

```bsl
Запрос = Новый Запрос;
Запрос.Текст =
"ВЫБРАТЬ
|   ...
|   ФасонныеИзделияКС,
|   НестандартныеИзделияКС,
|   ФасонныеИзделияПС,
|   НестандартныеИзделияПС,
|   ...
|ИЗ РегистрСведений.асЦеныПродукции.СрезПоследних(&Дата, Материал = &Материал)";
```

`&Дата = КонецДня(ДатаУстановкиЦен)`.

### 6.2 Выбор материала для цены

```bsl
Если Константы.асСчитатьПоЦенеМеталлаДляПроизводства.Получить() Тогда
    ВыбМатериал = Материал;
Иначе
    ВыбМатериал = ?(ЗначениеЗаполнено(Материал2), Материал2, Материал);
КонецЕсли;
```

В базе на момент исследования:

```json
{
  "асСчитатьПоЦенеМеталлаДляПроизводства": false,
  "асИспользоватьЦеныПоГруппам": true,
  "асРасчетЦеныВоздуховодаСУчетомЦеныФланцев": false
}
```

### 6.3 Цена за единицу

Основная формула для фасонки и воздуховодов:

```bsl
ЦенаЕд = Цена * S + ЦенаПоСпецификации + ЦенаПоСпецификацииВсехМатериалов;
Сумма  = ЦенаЕд * n;
```

Исключения:

- Если заполнена `Спецификация` строки → `ТипЦеныПоПрайсу = "ПоЦенеИзделия"`.
- Если цена по группе продукции найдена → `ЦенаЕд = ЦенаПоГруппеПродукции`.
- TDCR-флаги → принудительно `ПоЦенеИзделия`.

| Константа / параметр | Значение в базе | Влияние |

## 9. Подводные камни

1. **ТребуетсяПересчет**. Строка пропускается, если не установлен флаг `ТребуетсяПересчет`.
2. **`ТекущаяПрограмма1С = "КА"`**. Новый объект обработки создаётся с пустым значением; без него расчёт может пойти по другой ветке.
3. **`УчитыватьЗамкиВРасчетеПлощадиДляСчета = Истина`**. Без замков цена за единицу занижается (например, для 150×150×1250 S=0.75 вместо 0.793).
4. **Правильная точка входа**: `РедактироватьВсеНаКлиенте_ДляИзмененныхВМодуле()`, а не `РедактироватьВсеНаКлиентеВМодуле()` — последняя не вызывает `РасчетЦен`.
5. **Минимальные площади**. Маленькая фасонка автоматически переходит на нестандартную цену; для круглого порог 0.19 м², для прямоугольного 0.10 м².
6. **Сериализатор MCP** округляет числа до ~4 значащих разрядов. При сверке не путать с расхождением расчёта.
7. **Поля строки `Заказы`**. Названия отличаются от документа: `АртикулПродукции`, `АртикулГруппы`, `СечениеСтр`, `u` (угол), `D0`, `d1/d2/d3`, `A0/a1/a2`, `B0/b1/b2` и т.д.

## 10. Выводы

- Расчёт стоимости фасонных изделий в 1С «ВОК-Регион» — это многоэтапный процесс: геометрия → флаги прайса → цена из регистра → цена за единицу → сумма.
- Для фасонки цена почти всегда берётся по колонкам `ФасонныеИзделияКС` или `ФасонныеИзделияПС` регистра `асЦеныПродукции`, но при малой площади автоматически переключается на `НестандартныеИзделияКС/ПС`.
- Площадь `S` считается по специфическим для каждого артикула формулам с учётом замков (`Slock`), припусков CAMduct для круглых отводов и производных размеров из `асНастройкиПродукции`.
- Для воспроизведения расчёта вне 1С необходимо: иметь актуальный дамп формулы для каждого артикула, значения `Lock1/Lock2/Lock3`, параметры из `асНастройкиПродукции`, пороговые значения из `асЦеныПродукции` и текущие цены материалов.
- Порт 6005 предоставляет полноценный доступ к `execute_code`, что позволяет делать прямые пробы расчёта и валидировать собственные реализации.
