## Шины на соединение — поле `shina`

Код шины → материал, который обработка пропишет в `МатериалНаСоединение0/1`:

| shina | Наименование в асПродукция |
|---|---|
| 65 | Шина 20 / УГФ 65 (для нерж. — «Шина 20(нерж.430) / УГФ 65(нерж.430)») |
| 95 | Шина 20 / УГФ 95 |
| 105 | Шина 30 / УГФ 105 |
| "" | без шины |

В справочнике (снимок `ventilation_products_full.json`) заведены варианты:

| Наименование |
|---|
| Шина 20 / УГФ 65 (н) |
| Шина 20 / УГФ 75 (н) |
| Шина 20 / УГФ 85 (н) |
| Шина 20 / УГФ 95 (н) |
| Шина 30 / УГФ 105 (н) |
| Шина и УГФ |
